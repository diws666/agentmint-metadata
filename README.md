# AgentMint metadata

Public token metadata for the AgentMint free mint (Agent ID gated, BNB Chain).

- `1.json` … `2000.json` — one metadata file per token id.
- `image.png` — shared collection artwork.
- Base URI used by the contract: `https://raw.githubusercontent.com/diws666/agentmint-metadata/main/`
- Contract: AgentMint (see the AgentMint project repo for the verified source).
